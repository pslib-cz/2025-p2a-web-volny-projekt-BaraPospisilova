## Cílová skupina

_Kdo je váš cílový uživatel / zákazník? Popište typického zástupce cílové skupiny._

`-Až 72 % Čechů si dnes alespoň občas vyjede na kolo, takže zákazník může být od běžného Čecha, jenž pracuje od rána do večera přes nadšence do mountain bike, až po důchodce, který by uvítal elektrokolo. Takže typický zástupce cílové skupiny musí mít alespoň 35 000 kč, a chtít jezit.`
